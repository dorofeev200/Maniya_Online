## 1. Root cause FP «Матрица → Воскрешение»

Год-правило в `score()` (FIX-001) смотрит год ТОЛЬКО в титле (`collectYears(name)`):
поля `year` в API Rutube нет, но у сиквелов год лежит в **description** явным маркером
«Год: 2021». «Матрица: Воскрешение» (2021) набирал s=6 (startsWith +1, cat=4 +2,
dur≥5400 +2, hits≥200 +1) без каких-либо минусов → проходил MIN_SCORE=4 и был
лучшим кандидатом для запроса «Матрица (1999)». Точной записи «Матрица» (1999) в
индексе Rutube НЕТ (проверено глубоким сканом в READ-ONLY фазе) — exact-title бонус
некому применять, сиквел — единственный «фильм»-кандидат.

## 2. Изменения

### `server/src/providers/rutube/RutubeNormalizer.js`

1. В `score()` после титл-год-блока добавлен штраф за год описания:

   ```js
   if (!hasRequestedYear) {
     const descYear = collectDescYear(movie.description);
     if (descYear && descYear !== year) score -= 3;
   }
   ```

   - Титл-год в приоритете: если запрошенный год уже в ТИТЛЕ (exact title/year
     кандидат) — маркер описания не оспаривает его (не ломает «Интерстеллар (2014)»).

2. Новый хелпер `collectDescYear(description)` — читает ТОЛЬКО явный маркер
   «Год: NNNN» / «год NNNN» / «Год выпуска: NNNN»:

   ```js
   /год(?![а-яё])\s*[а-яё]{0,15}\s*[:–—-]?\s*(1[89]\d\d|20\d\d)/i
   ```

   - `(?![а-яё])` — «год» отдельным словом: отсекает «годовщину/году/годный»
     (там год обычно ПЕРЕД словом или не маркер). Никакого `\b` перед кириллицей —
     JS `\b` знает только ASCII и не видит границу перед «Г».
   - `\s*[а-яё]{0,15}\s*` — пропускает хвост « выпуска » (без него «Год выпуска»
     не матчилось: класс останавливался на пробеле).
   - Случайные 4-значные числа БЕЗ слова «год» ПЕРЕД числом не распознаются:
     «Интерстеллар (2014)» (1976 в desc, маркера нет) и «Зелёная Миля» (1960/2003
     в desc) штраф НЕ получают — иначе тонули бы полные копии.
