## 1. Изменения

### `server/src/providers/rutube/RutubeNormalizer.js`

Полная замена «первой прошедшей» на **scored ranking** (список баллов задокументирован в
исполнителе самого класса):

| Признак | Балл |
|---|---|
| title ≡ ключу (точное равенство) | **+3** |
| title начинается с ключа | +1 |
| точный год в титле (из полей API года нет — только подстрока) | +1 |
| **другой** год в титле (сиквел/чужая дата) | **−3** |
| категория-фильм {4,13,64,73} | +2 |
| шумовая категория (музыка/новости/игры/аниме/аудиокниги/…) | −2 |
| duration ≥ 5400 с (полнометраж) | +2 |
| 3000 < duration < 5400 | +1 |
| hits ≥ 200 | +1 |
| marker reaction/review/stream/саундтрек/дубляж/подкаст в титле (`TITLE_NOISE`) | −3 |
| монетизация/реакция в описании (`DESC_NOISE`: boosty/donate/twitch/патреон…) | −2 |

- `MIN_SCORE = 4` — проходной балл; `TOP_N = 3` — кандидатов провайдеру.
- `STRONG_SCORE = 5` — «сильная» запись (уверенное попадание). Новый метод `bestScore(raw)`
  возвращает максимальный балл в выдаче; `rankedCandidates()` — отсортированные кандидаты
  с `_score`. Сортировка: балл → длительность → стабильный id.
- Жёсткие safety-фильтры сохранены: `is_hidden/is_deleted/is_adult/is_locked/is_audio/
  is_paid/is_livestream`, `EXCLUDE_WORDS`, `duration > 3000`.
- Ключевые регуляризации по живому аудиту (2026-08-16):
  - категории фильмов расширены с строго `cat==4` до белого множества `{4,13,64,73}`
    (реальные копии встречаются под 73/13/64), шумовые категории — негативом;
  - **де-реакция на описание — тай-брейк −2, не гейт** −4: реакционные каналы заливают
    и полные копии («Интерстеллар (2014)» 10169с — desc с boosty), −4 топило реальные копии.

### `server/src/providers/rutube/RutubeProvider.js`

- **Мультиязычный поиск** (`buildQueries`): запросы RU и EN (`{title}` и `{original_title}`),
  до 2 строк, дедупликация ключей — решает FN «Аватар/Бойцовский клуб под англ. титлами».
- **Yearful-first + yearless-fallback**: сначала запросы с годом `{title} {year}`; если
  `bestScore(yearful) < STRONG_SCORE` (**нет ни одной сильной записи**) — повтор БЕЗ года.
  Решает главный кейс фикса: «Зелёная Миля» 6460с находится по «Зеленая миля», а не по
  «Зеленая миля 1999» (там top-2 страниц — пересказ/реакшн-шоу). Если бы фоллы случился
  только на пустую выдачу (как раньше), пересказ с s=4 блокировал бы фолбэк.
